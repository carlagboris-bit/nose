# Agenda pastel para GoodNotes

`Agenda_Pastel_2026-2027.pdf` — agenda digital con enlaces (noviembre 2026 – diciembre 2027):
portada, vista anual, página mensual por mes, una página semanal por semana, hábitos, prioridades y 6 páginas de notas.
Las pestañas laterales llevan a cada mes; los días y los botones «SEM» llevan a su semana.

**Importar en GoodNotes:** abre el PDF en el iPad → Compartir → GoodNotes → «Importar como documento nuevo».
Usa el modo lectura (o toca con el dedo si tienes desactivado «dibujar con el dedo») para seguir los enlaces.

Para regenerarla con otras fechas: cambia `INICIO`/`FIN` en `generar_agenda.py` y ejecuta `python3 generar_agenda.py` (requiere `reportlab`).
Fuentes: Quicksand, Playfair Display y Dancing Script (licencia SIL OFL).
